# ProyectosDeAula — lo que este proyecto toma del curso

**Construcción de Software no es un módulo de ProyectosDeAula.** Su dominio es
`bdfacturas`, no un módulo de la Facultad.

Lo que sí comparte es **el método**, y de ahí viene lo único que se copió aquí:

| Archivo | Para qué lo usa este proyecto |
|---|---|
| [`docs/0_METODOLOGIA.md`](docs/0_METODOLOGIA.md) | **Las cuatro versiones** y sus reglas de oro. Es lo que ordena [`0_mapa_versiones.md`](../docs/spec_kit/versiones/0_mapa_versiones.md) |
| `docs/CONCEPTOS_ELICITACION.md` | Cómo se levantan los requisitos |
| `docs/CONCEPTOS_HISTORIAS_DE_USUARIO.md` | Cómo se escriben las historias |
| `docs/CONCEPTOS_PLAN_DE_DESARROLLO.md` | Cómo se reparte el trabajo en versiones |

**No se copiaron** los módulos de aula —investigación, gestión profesoral,
innovación curricular, mapa de conocimiento— ni sus bases de datos, ni sus
entrevistas: son otro dominio. Si necesita verlos, están en
`proyecto_investigacion1/ProyectosDeAula/`.
